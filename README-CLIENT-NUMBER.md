# PAR ORDO PRO — номер клиента считается по смене

Раньше на браслете было «Клиент 45 (№6)»: сервер нумерует гостей каждого браслета за всё время
(№6 — 45-й гость за всю историю). Теперь номер считается **внутри смены и отдельно по каждому браслету**:

- первый гость новой смены на №6 — «Клиент 1 (№6)», следующий на №6 — «Клиент 2 (№6)»;
- смена закрылась — счёт обнуляется, в новой смене снова с 1;
- номер одинаковый везде: карточка браслета, окно клиента, «Добавить покупку», подтверждение
  завершения, сообщение при выдаче браслета, История, Архив, браслет руководителя №3.

Как устроено:

- Номер с сервера (`clientNo`) не меняется и остаётся в данных как внутренний сквозной номер
  (руководитель видит его в карточке как «Внутренний номер клиента»). Новый номер — только для экрана.
- Гости текущей смены нумеруются по времени выдачи браслета, начиная с открытия смены.
- Гости прошлых смен в Истории/Архиве нумеруются внутри своей смены по отчётам смен. Пока отчёты
  не загружены — внутри дня визита.

Файлы: `index.html` (функция `shiftClientNo`), `par-ordo-sections-v1.js` (1.0.2),
`par-ordo-bracelet-rules-v108.js`, `par-ordo-bonus-v1.js` (1.0.1, передаёт отчёты смен для нумерации).
