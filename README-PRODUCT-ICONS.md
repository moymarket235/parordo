# PAR ORDO PRO — PRODUCT ICONS V1 · живые иконки товаров

Вместо плитки с названием («ЖАРМА», «ЖИВАЯ») у каждого товара теперь своя анимированная иконка.
Название на иконке больше не пишется. Отступ между иконкой и названием исправлен.

## Где видно

- **Товары** — карточки товаров (иконка 58 px, между иконкой и названием 14 px) и таблица на ПК.
- **Добавить покупку** — плитки товаров (иконка 60 px).
- **Браслет гостя** — список покупок.

## Как выбирается иконка

По названию товара. Если слово не распознано — по категории, иначе подарочная коробка.
Цвет, узор и ритм движения дополнительно зависят от самого названия, поэтому даже похожие товары
(две воды, три веника, разные полотенца) выглядят по-разному.

Бренды (Nivea, Dove, Axe, Old Spice, Rexona, Clear, FORX, Viking, Garnier, Fa, Deonica, Gillette…)
дают иконке свои цвета. Логотипы не рисуются.

Если у товара загружено настоящее фото (адрес https или data:image), показывается фото с бегущим бликом.
Старые сгенерированные картинки из `assets/products/` больше не используются.

## Скорость и батарея

- Двигаются только иконки, которые сейчас на экране; ушедшие с экрана замирают.
- Иконка «влетает» один раз — когда товар впервые появляется на экране.
- В системе включено «уменьшить движение» — иконки показываются без анимации.
