# ПАР ОРДО — 10/10 mobile-first site starter

## Что уже есть
- Домашняя страница в тёмном wood/steam стиле из референса.
- Каталог: одноразовые шорты, полотенца, мыло, мужские трусы, носки, веник для пара, напитки.
- `В наличии · N шт.` для каждой позиции.
- Корзина, изменение количества, оформление заказа.
- QR / наличные сценарии, номер заказа, статус.
- История заказов и экран уведомлений.
- Instagram / WhatsApp кнопки через `CONFIG` в `app.js`.
- Время работы: 10:00–23:00, без выходных; доставка отсутствует.
- PWA manifest + service worker scaffold.
- Отдельный `admin.html` с остатками, заказами и базовой статистикой.

## Что подключается на следующем этапе
GitHub Pages — только фронтенд. Для реального общего склада, админов, оплат и push нужен backend. Рекомендуемая схема: GitHub Pages → Cloudflare Worker/API → D1 (товары/заказы/движения) + KV/R2 (служебные данные) → web-push; для реальной QR-оплаты backend должен получать подтверждение платежа через API/webhook провайдера.

### Важно для Push
Push-уведомления работают только после явного разрешения пользователя. Расписание 3–4 уведомления/день нужно делать на backend по opt-in базе и с настройками пользователя (например, акции / новые товары / важные новости) — не отправлять без согласия.

### Перед публикацией
1. В `app.js` замените `instagramUrl` и `whatsappGroupUrl` на реальные ссылки.
2. Замените demo QR на QR от выбранного платёжного провайдера.
3. Подключите API и авторизацию админки; не храните пароли администратора в GitHub/JS.


## V2 — актуальные товары
В каталог добавлены предоставленные пользователем изображения Пар Ордо для: одноразовых шорт (взрослые/детские), мыла, полотенец, мужских трусов, носков, веника, чая, минеральной воды и напитков.

Цены намеренно не заполнены. В админ-панели есть поле **Цена (сом)** для каждого товара; после сохранения цена автоматически появится в каталоге, корзине и оформлении заказа. Количество также можно вводить/изменять и добавлять через поле **Поступление +**.

Доставка не используется: получение товара — непосредственно в ПАР ОРДО.
