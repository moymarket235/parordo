# PAR ORDO PRO — DEAL V1 · «Браслет таратуу»

Открытие экрана «Номера и клиенты»: все видимые карточки (hero, смена, CLEAN CONTROL PRO,
PAR ORDO GO · QR сканер, KPI, база клиентов, браслеты) собираются в колоду ПАР ОРДО
в центре экрана и раздаются на свои места, переворачиваясь лицом в полёте.
Браслеты ниже экрана раздаются при первом скролле. Один браслет — одна раздача за сессию.

## Что загрузить в корень репозитория (с заменой)

- `index.html` — 3 небольшие вставки (скрипт в `<head>`, подключение CSS и JS)
- `par-ordo-vault-v1.js` — сейф после входа отдаёт карточки раздаче (старая анимация осталась запасной)
- `par-ordo-deal-v1.js` — новый файл, вся анимация
- `par-ordo-deal-v1.css` — новый файл, рубашка карты и колода ожидания
- `assets/par-ordo-deal-logo.webp` — новый файл, логотип 200 px для рубашки (15 КБ)

## Когда играет

- После входа (сейф): дверь открывается → карточки раздаются.
- При открытии с сохранённой сессией: пока грузятся данные, в центре «дышит» колода,
  затем карточки раздаются (не дольше ~2.3 с).
- Касание, клавиша или скролл во время ожидания — анимация отменяется, панель видна сразу.
- `prefers-reduced-motion` — без анимации.

## Безопасность

API, вход, смена, `renderRooms()` и логика браслетов не изменены. Только transform/opacity
через Web Animations API; все временные элементы удаляются. Если JS не загрузился —
панель показывается сразу (onerror + страховка 6 с).

Отключить: удалить строки `par-ordo-deal-v1.*` и `po-deal-armed` из `index.html` —
сейф вернётся к своей старой анимации автоматически.
