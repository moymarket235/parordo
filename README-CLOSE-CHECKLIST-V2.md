# PAR ORDO PRO — ПРОВЕРКА ЗАКРЫТИЯ СМЕНЫ V2 · «щит обхода» + Worker V10.18

Перед закрытием смены сотрудник отвечает «Да / Нет» на 8 вопросов и при необходимости пишет
комментарий. Ответы сохраняются в отчёте смены на сервере, руководитель видит их в
«Касса и отчёты» и в «Ежедневном отчёте».

## Что загрузить

**GitHub (корень репозитория, с заменой):**

- `index.html` — чек-лист в «Итог», чек в окне подтверждения, блок в «Касса и отчёты»
- `par-ordo-inner-v1.js` — раздел «Проверка закрытия» в «Ежедневном отчёте» (INNER `1.0.2`)
- `par-ordo-inner-v1.css` — стили этого раздела

**Cloudflare Worker (`par-ordo-api`):**

- `worker.js` — Worker API V10.18. Workers & Pages → par-ordo-api → Edit code → заменить весь
  код содержимым `worker.js` → Deploy. Секреты (пароли) и база D1 не меняются, миграция не нужна:
  чек-лист хранится внутри `payload_json` отчёта.
- Проверка: `https://par-ordo-api.moimarketjibekjolu.workers.dev/api/health` → `"version":"10.18"`.

Порядок не важен, но лучше сначала Worker, затем GitHub: тогда уже первая закрытая смена
сохранит ответы. `sw.js` обновлять не нужно.

## Дизайн V2 · «щит обхода»

- **Итог (сотрудник, администратор):** латунная панель. Кольцо прогресса «4/8», у каждого пункта
  своя иконка (огонь, пар, вода, газовый кран, вентилятор, поток воздуха, лампа, замок),
  индикаторная лампа (не горит / зелёная / красная) и переключатель «Да / Нет» со скользящей
  кнопкой. «Комментарий» открывает поле; при «Нет» поле открывается само и обязательно.
  Когда ответы даны, внизу ставится печать «Проверка завершена · Пар Ордо» со временем:
  зелёная — всё в порядке, красная — есть замечания.
- **Окно «Завершить рабочую смену?»:** под Z-отчётом печатается второй чек «Проверка закрытия»
  с ответами ДА / НЕТ и комментариями.
- **Касса и отчёты (руководитель, администратор):** «Проверка закрытия смен» — последние 6 смен:
  дата и время, кто закрыл, счёт «7/8», полоса из 8 ламп с иконками (красная — замечание),
  замечания с комментариями, «Все ответы».
- **Ежедневный отчёт:** чип дня «Проверка: всё в порядке» / «Проверка: 1 замечание»
  (нажатие открывает этот день и прокручивает к ответам) и раздел «Проверка закрытия»
  после «Смены» с тем же видом: печать, счёт, лампы, замечания, ответы.
- Движение: только скольжение переключателя, кольцо прогресса и удар печати при завершении.
  `prefers-reduced-motion` — без анимации.

## Как работает

- Смену нельзя завершить, пока нет ответа на все 8 вопросов и комментария к каждому «Нет».
  Незаполненные пункты подсвечиваются, экран прокручивается к первому из них.
- Ответы хранятся на устройстве до закрытия смены (перезагрузка их не стирает) и очищаются
  после успешной отправки. Новая смена — чистый чек-лист.
- Отчёт отправляется с полем `closingChecklist`. Если сервер его не принял (старый Worker),
  отчёт автоматически уходит без чек-листа — закрытие смены не блокируется, сотрудник видит
  предупреждение «нужно обновить Worker API».

## Worker API V10.18

`closeControlShift()` принимает `closingChecklist`, проверяет и сохраняет его в отчёте:

- до 20 пунктов; ключ — только `a-z A-Z 0-9 _ -`; вопрос до 200 символов, комментарий до 500;
- ответ только `yes` / `no`, иначе пустой и считается замечанием;
- итоги (`total`, `okCount`, `problemCount`, `allOk`, `summary`) сервер считает сам,
  значения из приложения не принимаются; `completedBy` — вошедший пользователь;
- без чек-листа или с неверным чек-листом смена закрывается как раньше;
- чек-лист возвращается в ответе `POST` и в `GET /api/admin/control/reports`
  (руководителю и администратору; сотрудник по-прежнему видит только дату последнего закрытия);
- в журнал `shift_closed` добавлена сводка: всего / в порядке / замечаний.

Формат, который отправляет приложение:

```json
{
  "shiftDate": "2026-11-15",
  "shiftStartAt": "2026-11-15T03:00:00.000Z",
  "closedBy": "staff",
  "closingChecklist": {
    "version": 1,
    "items": [
      { "key": "fire", "order": 1, "question": "Огонь выключен?", "answer": "yes", "comment": "" },
      { "key": "gas", "order": 4, "question": "Газ выключен?", "answer": "no", "comment": "Кран заедает, перекрыл вручную" }
    ]
  }
}
```

Ключи пунктов: `fire`, `steamGenerator`, `hotWater`, `gas`, `steamRoomHood`, `lights`,
`bathHood`, `doors`.
