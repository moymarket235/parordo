# PAR ORDO PRO — EXPENSES V1 · «Расходы бани»

Новый экран раздела «Расходы бани»:

- **Вариант 1 «Гроссбух»** — показ: сумма за месяц, категории, журнал по дням.
- **Вариант 3 «Тез кошуу»** — быстрое добавление расхода с цифровой клавиатуры.

API, Worker и формат записи не меняются. Сохранение идёт через оригинальную функцию
`saveExpenseEntry()`, тем же запросом `POST /api/admin/control/expenses`
с теми же полями: `title`, `category`, `amount`, `method`, `spentAt`, `note`.

## Что загрузить в корень репозитория (с заменой)

- `index.html` — 2 новые строки: CSS после `par-ordo-sections-v1.css`, JS после `par-ordo-sections-v1.js`
- `par-ordo-expenses-v1.js` — новый файл
- `par-ordo-expenses-v1.css` — новый файл

Этот `index.html` подключает также DEAL V1 и SECTIONS V1. Если они ещё не загружены,
загрузите и их файлы (они лежат в этом же архиве): `par-ordo-deal-v1.*`, `par-ordo-vault-v1.js`,
`assets/par-ordo-deal-logo.webp`, `par-ordo-sections-v1.*`.

## Экран «Гроссбух» (показ)

- **Месяц одной цифрой** — сумма расходов за месяц, число записей.
  Плитки: Сегодня / В день (среднее) / Крупнейший. Полоса «Наличные / Перевод / Другое».
- **По категориям** — общая полоса и строки категорий: иконка, сумма, доля в %.
  Категории без расходов собраны в одну строку «Ещё N — без расходов».
- **Журнал** — записи по дням («Вчера · пн, 9 ноября»), итог дня справа.
  В строке: название, категория, способ оплаты, кто записал, примечание, сумма.
  Показываются 40 записей, дальше кнопка «Показать ещё».
- Кнопка «Обновить» оставляет журнал на экране, пока идёт загрузка.

## Экран «Тез кошуу» (добавление)

Открывается кнопкой **«＋ Добавить расход»** внизу экрана.

1. Сумма набирается на клавиатуре (`1–9`, `00`, `0`, стереть).
2. «На что потратили» — обязательно (минимум 2 символа).
3. Категория — 7 категорий из прежней формы; последняя выбранная запоминается.
4. Способ — Наличные / Перевод / Другое; последний выбранный запоминается.
5. Дата — Сегодня / Вчера / Дата из календаря.
6. Примечание — по желанию.
7. «Сохранить · N сом» → печатается чек, затем экран закрывается и новая
   строка подсвечивается в журнале. Сумма месяца и категории обновляются.

Ошибки: без суммы или без названия — поле подсвечивается и трясётся.
Если сервер не ответил — показывается сообщение приложения, введённые данные остаются.

На ПК работает клавиатура: цифры, Backspace, Enter — сохранить, Esc — закрыть.

## Роли

- **Персонал / администратор** — просмотр и добавление.
- **Руководитель** — только просмотр: кнопки добавления нет, показывается прежняя подсказка
  «Режим руководителя…». Сервер и его проверки не меняются.

## Анимации

- Первый заход в раздел — полная анимация (сумма считается, журнал «пишется»);
  дальше — короткая (~0.3 с).
- `prefers-reduced-motion` — новый дизайн без анимации.

## Безопасность и откат

- Подменяется только отрисовка `renderExpenseData`; `loadExpenses` и `navigate` обёрнуты
  и вызывают оригинал. При любой ошибке модуля показывается прежняя отрисовка.
- Прежняя форма не удаляется: она скрыта и используется как канал сохранения.
- В `localStorage` пишутся только `po_ex_cat` и `po_ex_method` (последняя категория и способ).

Отключить: удалить две строки `par-ordo-expenses-v1.*` из `index.html` — вернётся прежний экран.
