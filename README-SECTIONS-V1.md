# PAR ORDO PRO — SECTIONS V1 · новые экраны и анимации входа

Новый вид и собственная анимация появления для разделов: Товары, История, Архив,
Итог (касса + Z-отчёт), меню и вход руководителя. Данные, API, смена, оплаты и склад
не меняются: экраны строятся из тех же `db` и `shiftState`.

## Что загрузить в корень репозитория (с заменой)

- `index.html` — 2 строки: CSS после `par-ordo-deal-v1.css`, JS в самом конце `<body>`
- `par-ordo-sections-v1.js` — новый файл
- `par-ordo-sections-v1.css` — новый файл

Если DEAL V1 ещё не загружен, загрузите и его файлы (`par-ordo-deal-v1.*`,
`par-ordo-vault-v1.js`, `assets/par-ordo-deal-logo.webp`): этот `index.html` подключает оба модуля.

## Разделы

- **История** — чеки на ленте времени, сгруппированы по дням (Сегодня / Вчера / дата).
  Время сеанса с лимитом 3 ч (красная шкала, если больше), строки с точкой способа оплаты,
  печать «✓ Завершён». Вход: чеки «печатаются» из принтера, печать опускается штампом.
- **Архив** — поиск (браслет, клиент, товар, дата), папки по дням: последняя открыта,
  остальные свёрнуты, по 10 дней с кнопкой «Показать предыдущие дни». Строки раскрываются.
- **Итог** — открытая смена: живой таймер, барабан суммы, наличные / перевод / ожидает,
  плитки (клиенты, средний чек, не оплачено), входы и товары. Закрытая смена — как раньше.
- **Z-отчёт** — в окне «Завершить рабочую смену?» печатается кассовый чек смены.
  Предупреждения сверху, если есть активные клиенты или неоплаченные позиции.
  Кнопки «Назад» / «Завершить» и сама логика закрытия смены не изменены.
- **Товары** — карточка «Продано на сумму», прибыль, плитка «Проверить категории»
  (открывает «Все товары»), карточки категорий с иконками, долей выручки и шкалой продаж.
  Переключатель **Сетка / Список** (запоминается): сетка падает на полки, список
  проходит лазер-сканер.
- **Меню** — медальон, группы Работа / Касса / Управление, карточка смены,
  живые бейджи (активные, история, сумма кассы). На ПК меняется только содержимое сайдбара.
- **Вход руководителя** — замок, кольцо ожидания, тряска при ошибке, при успехе замок
  открывается («Доступ открыт») и собирается панель руководителя.

## Когда играет

- Первый заход в раздел после запуска — полная анимация; дальше — короткая (~0.3 с).
- Карточки ниже экрана появляются при первом скролле.
- `prefers-reduced-motion` — новый дизайн без анимации.

## Безопасность

Без API-запросов и записи. Подменяются только `renderHistory` и `renderArchive`;
`renderReport`, `confirmAction`, `closeModal`, `navigate` обёрнуты и вызывают оригинал.
Любая ошибка модуля пишется в консоль, экран остаётся рабочим.

Отключить: удалить две строки `par-ordo-sections-v1.*` из `index.html`.
