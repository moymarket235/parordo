# ДЖАРВИС V2: сайттын толук жардамчысы (PAR ORDO PRO)

Джарвис эми төрт нерсени жасайт:
- **Тосуп алат.** Сайтка киргенде «Добро пожаловать в PAR ORDO PRO, сэр» деп айтат.
- **Суроолорго жооп берет.** Сайттын ичиндеги маалыматты карточка менен көрсөтүп, үн менен айтып берет.
- **Бөлүмдөрдү ачат.** Сайттын каалаган бөлүмүн үн менен ачат.
- **Жол көрсөтөт.** «Как закрыть смену?» сыяктуу суроолорго кадам-кадамы менен жооп берет.

Ал «Руководитель панели» ичинде да иштейт.

Worker'ге тийбейт: GitHub'га 2 файл жүктөсөңүз жетиштүү.

## 1. GitHub'га жүктөө

1. ZIP'ти ачып, 2 файлды сактаңыз:
   - `index.html`
   - `par-ordo-jarvis-v1.js`
2. github.com/moymarket235/parordo → **Add file → Upload files** → эки файлды тең тандаңыз → **Commit changes**.
3. 1–2 мүнөттөн кийин сайтты кайра ачыңыз.

V1 коюлган болсо да, эки файлды тең кайра жүктөңүз. `index.html` ичинде жаңы версия (`v=2.0.0`) жазылган, ошондуктан телефон эски файлды көрсөтпөйт.

## 2. Тосуп алуу

Сайтка логин менен киргенде Джарвис мындай деп айтат:
«Добро пожаловать в Пар Ордо Про, сэр. Смена открыта, активных браслетов: 4».

- Экрандын башында алтын түстөгү тосуу карточкасы да чыгат.
- Тосуу бир сессияда бир гана жолу айтылат.
- «Руководитель панели» ачылганда: «Добро пожаловать в панель руководителя, сэр».

Браузердин эрежеси боюнча, сайт өзүнөн-өзү үн чыгара албайт. Логин баскычын басканда бул шарт аткарылат. Эгер сайт логинсиз ачылса, үн экранга биринчи тийгенде чыгат.

- «Как отметить оплату?»

- «Как добавить товар?»

- «Как зарегистрировать клиента?»

Ар бир жоопто кадамдар жана бөлүмдү ачуучу баскыч бар.

«Открой смену» десеңиз, Джарвис ырастоону сурайт, анан сменаны өзү ачат.

## 6. Руководитель панели

Джарвис баскычы «Руководитель панели» ичинде да чыгат. Руководитель мындай сурай алат:
- «Прибыль за месяц»
- «Отчёт за вчера»
- «Выручка за неделю»
- «Топ товаров за месяц»
- «Статистика товаров»
- «Ежедневный отчёт»

Руководитель режиминде Джарвис маалыматты гана көрсөтөт. Браслет жана покупкаларды персонал жүргүзөт.

Сотрудник өткөн сменалардын отчётун жана пайданы көрө албайт. Джарвис ал маалымат руководителге гана ачык экенин айтып берет.

## 7. Жөндөөлөр (⚙)

- **Тил:** Русский, Кыргызча же Казахский.
- **Отвечать голосом:** үн менен жооп берүү.
- **Приветствие при входе:** тосуп алууну өчүрүү же күйгүзүү.
- **Обращение:** Сэр, Госпожа же Без обращения.
- **Выученные слова:** Джарвис үйрөнгөн сөздөрдүн тизмеси. Керексизин «Забыть» менен өчүрүңүз.
