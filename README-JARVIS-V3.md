# PAR ORDO PRO — Джарвис V3

## Эмне жаңы

**1. Эркек үн**
- **Бекер жол:** телефондун эркек үнү жана бир аз төмөн тон.
- **Тирүү үн (каалаган учурда):** Google'дун табигый эркек үнү. Бардык телефондо бирдей угулат. Ага Worker V10.20 жана Google ачкычы керек (төмөндө).
- **Чынын айтсак:** кинодогу J.A.R.V.I.S.'тин үнү — актёр Пол Беттанинин өз үнү. Аны уруксатсыз көчүрүүгө болбойт. Ошондуктан ага окшош стилдеги, токтоо, салмактуу эркек үн тандалды. «Сэр» деп кайрылуусу ошол бойдон калат.

**2. Сумма кыска жана так айтылат**
- 2345 → «две триста сорок пять сом» (кассир айткандай). Мурда «две тысячи триста сорок пять» деп созуп айтчу.
- Жалпы итогдор 10 000ден ашса, миңге чейин тегеректелет: 24 350 → «двадцать четыре тысячи сом». Муну ⚙ жөндөөдөн өчүрсө болот.
- Цифралар сөз менен жазылып берилет, ошондуктан телефон аларды бирден окубайт.
- Сүйлөм кыскарды: бир жоопто 1–2 сан гана айтылат. Карточкада баары цифра менен так көрүнөт.
- Демейки ылдамдык — 1.1. Жөндөөдөн өзгөртсө болот.

**3. Джарвис өзү эскертет**
- **Браслет 2:50:** «Сэр, браслет 7: через 10 минут три часа.»
- **Браслет 3:00:** «Браслет 7: три часа прошло, добавлен вход триста сом.»
- **Склад:** товардан 2 даана калганда же товар бүткөндө — «Самса: осталось 2» / «Нет в наличии: самса».
- Эскертүү экрандын үстүндө чыгат, жанында «Открыть» же «Склад» баскычы болот.
- Ар бир эскертүү бир жолу гана айтылат. Барак жаңыланганда кайталанбайт.
- Ким угат: персонал жана администратор, смена ачык кезде. Руководитель панелинде айтылбайт. №3 (руководителдин браслети) айтылбайт.
- Телефон экранга бир жолу тийгенден кийин гана сүйлөйт — бул браузердин эрежеси.

## 1. Сайтка орнотуу (2 файл)

1. GitHub → репозиторий → **Add file → Upload files**.
2. `index.html` жана `par-ordo-jarvis-v1.js` файлдарын жүктөңүз (эскилерин алмаштырат).
3. **Commit changes** басыңыз.
4. 1–2 мүнөт күтүп, сайтты жаңылаңыз.

Текшерүү: Джарвисти ачып → ⚙ → «Прослушать». «Две триста сорок пять сом» деп айтышы керек.

## 2. Бекер эркек үн — ар бир Android телефондо бир жолу

Android'де Chrome тандалган үндү тутумдан (телефондун жөндөөсүнөн) алат.

1. Телефондун **Настройки** → издөөгө **«Синтез речи»** (же «Text-to-speech») деп жазыңыз.
2. **Синтезатор:** «Речевые сервисы Google» болушу керек.
3. Анын жанындагы ⚙ → **«Установка голосовых данных»** → **Русский (Россия)**.
4. Үндөрдү бирден угуп көрүп, **эркек үндү** тандаңыз.
5. Сайтка кайтып: Джарвис → ⚙ → «Прослушать».

Тон: Джарвис ⚙ → «Тон голоса телефона». Канча аз болсо, үн ошончо жоон угулат.

iPhone үчүн: Настройки → Универсальный доступ → Устный контент → Голоса → Русский → **Yuri** (эркек).

## 3. Тирүү үн — Google (каалоо боюнча)

Мунун пайдасы: бардык телефондо бирдей, табигый эркек үн угулат. Ар бир телефондун жөндөөсүн өзгөртүүнүн кереги жок.

### А. Google Cloud (бир жолу)
1. **console.cloud.google.com** сайтына Gmail менен кириңиз → жаңы долбоор түзүңүз (мисалы `par-ordo-voice`).
2. **Billing** → карта кошуңуз. Бекер чек үчүн да карта милдеттүү.
3. **APIs & Services → Library** → издөөгө «**Cloud Text-to-Speech API**» деп жазып → **Enable**.
4. **APIs & Services → Credentials → Create credentials → API key** басып, ачкычты көчүрүп алыңыз.
5. Ачкычтын жөндөөсүнөн: **API restrictions → Restrict key → Cloud Text-to-Speech API** → **Save**.
   «Application restrictions» бөлүгүн **None** бойдон калтырыңыз.
6. Тынч болуш үчүн: **Billing → Budgets & alerts** → $1 бюджет коюп, email эскертүү күйгүзүңүз.

### Б. Cloudflare Worker
1. **Workers & Pages → par-ordo-api → Settings → Variables and Secrets → Add**.
2. Type: **Secret**, Name: `GOOGLE_TTS_KEY`, Value: Google ачкычы → **Deploy**.
3. **Edit code** ачып, кодду эң аягына чейин түшүрүңүз.
4. `worker-addon-V10.20-mini.txt` файлынын ичиндегисин **эң аягына** (V10.19 кошумчасынан кийин) кошуңуз → **Deploy**.
   Мурунку кодго тийбеңиз.

### В. Текшерүү
`https://par-ordo-api.moimarketjibekjolu.workers.dev/api/health`
- `"version":"10.20"` жана `"features"` ичинде `"jarvis-tts"` болушу керек.
- Сайтта: Джарвис → ⚙ → «**Живой голос Джарвиса подключён**» деп жазылат.
- 6 үн бар: Charon (демейки), Algieba, Schedar, Orus, Iapetus, Algenib. Биринин үстүнө басса, ошол үн менен айтып берет.

### Баасы
- Google'дун Chirp 3 HD үндөрү: айына биринчи 1 миллион тамга бекер. Андан ашса, 1 миллион тамгага $30.
- Джарвистин бир фразасы 40–50 тамга. Демек, күнүнө 700гө жакын фраза бекер чекке батат.
- Кайталанган фразалар телефондо сакталып калат, аларга кайра акча кетпейт.
- Google иштебей калса (ачкыч, интернет), Джарвис өзү телефондун үнүнө өтөт. Жумуш токтобойт.

- Отвечать голосом
- Голос Джарвиса — тирүү үн, 6 үндүн бирин тандоо
- Голос телефона — «Авто» (эркек үн болсо, ошону тандайт)
- Скорость речи, Тон, **Прослушать**
- Итоги от 10 000 — до тысяч
- Предупреждения: браслеттер (2:50 / 3:00), склад (2 даана / бүттү)
- Тил, саламдашуу, кайрылуу («Сэр»), үйрөнгөн сөздөр — мурдагыдай
